# GeoBazar FINAL CLEAN UPLOAD

Это финальный пакет для чистой загрузки сайта.

## Цель
Загрузить один пакет, чтобы весь сайт был в едином премиум-стиле:
- без флагов в баннере;
- выбор языка только сверху;
- на главной только популярные категории;
- остальные категории через поиск и страницу Все категории;
- единый стиль кабинета, CRM, объявлений, карты и платежей;
- AI-кнопка остаётся как заглушка для финального этапа.

## Как загрузить правильно

### Вариант А — лучший
1. Создать новый GitHub репозиторий: geobazar-v2
2. Загрузить туда ВСЕ файлы из этого архива.
3. В Cloudflare подключить новый репозиторий.
4. Старый репозиторий оставить как резервную копию.

### Вариант Б — если остаёмся в старом репозитории
1. Удалить старые файлы дизайна:
   - premium.css
   - premium-home.css
   - старые дубликаты index/dashboard/listings если есть
2. Загрузить ВСЕ файлы из этого архива с заменой.
3. Проверить, что в корне есть:
   - index.html
   - style.css
   - premium-all.css
   - config.js
   - ui.js
   - auth.js
4. Открыть сайт:
   geobazar.ge/index.html?v=final10
5. Нажать Ctrl + F5.
